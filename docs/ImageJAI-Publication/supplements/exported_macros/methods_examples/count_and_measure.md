Why so many `[unknown]`s on a public BBBC image: BBBC020 ships TIFFs with
minimal OME-XML — channel name + pixel size + emission wavelength are
typical, but microscope and objective metadata are not embedded. Author
fills these from the dataset card before submission. The point of the
exporter is that the analysis-side fields (plugins, parameters,
calibration, dimensions) auto-populate; the acquisition-side fields are
the ones a human always has to confirm.
